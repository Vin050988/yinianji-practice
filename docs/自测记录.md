## 二、关键实现点（对照规范逐条落实）

| 规范条款 | 实现位置 | 说明 |
|---|---|---|
| 3.4 倒计时用**时间戳差值** | `js/modes.js` `s.remaining()` | `剩余 = 时长 − (now − 开始时刻)`，`setInterval` 只负责渲染；切后台回来立即重算，**不白送时间** |
| 5.7 口算 4 条硬约束 | `js/engine.js` `makeArith()` | ①结果在 [minResult, maxResult]；②减法先定 a 再在 `0..a` 抽 b；③会话内 `(a,op,b)` 去重；④兼容 `{op}` 占位符与写死运算符 |
| 3.7 适龄要求 | `css/app.css` | 按钮 `--tap: 88px`、题干 30px、正文 20px、拼音 `rt` 0.42em |
| 5.5 拼音字段 | `js/pinyin.js` | 音节按汉字顺序对应，标点/数字不占位；拼音不足时不错位 |
| 2 节 无外部依赖 | 全部资源本地 | 无 CDN、无外链图片（校验器强制） |
| 3.3 闯关/配对 | `js/app.js` | 闯关（3 条命、连击）已实现；配对玩法作为题型已可用；计时挑战/竞速保留接口 |

| 3.5 错题本 | `js/storage.js` | 答错自动收录，连续答对 2 次移出 |
| 2 节 PWA | `manifest.json` + `sw.js` | 预缓存外壳与题库、断网兜底；iOS 添加到主屏幕可全屏 |

## 三、需要你在真机上看一眼的（我无法自动验证）

1. **视觉效果**：题目卡片、拼音注音、撒花动画是否好看、字号是否够大；
2. **手感**：按钮大小是否适合孩子手指；横竖屏切换；
3. **语音朗读**：iPad Safari 中文 TTS 是否出声（不出声也不影响答题，题目有拼音）；
4. **切后台计时**：进入答题后切到别的 App 一分钟再回来，看计时是否照常走（这是规范要求的验证点）；
5. **加到主屏幕**：分享 → 添加到主屏幕 → 点图标是否全屏打开（需要部署到 https 后才能验证，见阶段 3）。
