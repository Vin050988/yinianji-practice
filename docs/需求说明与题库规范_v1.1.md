## 1. 项目概述

| 项 | 内容 |
|---|---|
| 目标用户 | 深圳小学一年级学生（6~7 岁）+ 家长 |
| 使用设备 | **iPad 为主**（Safari 打开 → 添加到主屏幕 → 全屏像 App）；Mac/PC 浏览器可调试 |
| 覆盖学科 | 语文、数学（**本批**）；英语（占位，教材到手后按同一规范补充） |
| 核心用途 | 课后复习练习，游戏化答题，不做成干巴巴的刷题 |
| 单次时长 | **每科每天 ≤ 10 分钟**（程序强制计时，家长可调） |
| 产品形态 | 静态网页应用（PWA），个人使用、不上架、无需开发者账号 |
| 部署形态 | **GitHub Pages（https）** |
| 一句话目标 | 孩子每天每科玩 10 分钟、答对题、拿星星；家长能看成绩；不超时、不枯燥 |

## 2. 技术选型与交付形态（v1.1 修订）

- **单页应用**：HTML + CSS + 原生 JavaScript。不依赖构建工具、**不依赖任何外部 CDN**。
- **部署形态**：静态站点，托管在 **GitHub Pages（https）**。
  家长流程：iPad Safari 打开站点 → 分享 → 「添加到主屏幕」→ 以后点图标全屏使用。
- **允许联网**（体验优先）：题库 JSON 通过 `fetch()` 加载是**正常且推荐**的做法（https 下不受限制）。
- **不支持 `file://` 双击打开**（`fetch` 会被 CORS 拦、Service Worker 无法注册）。
  本地调试请用：`cd 一年级练习App && python3 -m http.server 8000`，浏览器访问 `http://localhost:8000`。
- **Service Worker**：缓存应用外壳 + 题库，**断网时兜底可玩**（属于加分项，不是硬性离线要求）。
- **本地存储**：`localStorage` 保存成绩记录、设置、错题本、打卡。
- **语音**：Web Speech API（TTS）朗读题干；对错音效用 Web Audio 合成，不需要音频素材文件。
  **必须有无声降级**：TTS 不可用时（语音包缺失/被系统禁止）题目仍可正常作答，靠拼音与按钮提示。
- **交付物**：一个文件夹

```
一年级练习App/
├── index.html
├── manifest.json          # PWA 清单（含 apple-touch-icon）
├── sw.js                  # Service Worker
├── css/app.css
├── js/                    # app.js / engine.js / modes.js / storage.js / audio.js / pinyin.js
├── data/                  # yuwen-1-up.json / shuxue-1-up.json / yingyu-1-up.json
├── assets/                # 图标、自制 SVG 配图
└── docs/                  # 本规范、题库修订报告、安装到 iPad 指引
```

## 3. 功能需求

### 3.1 页面结构（共 5 个页面）

1. **首页（选科）**：三张大卡片「语文 / 数学 / 英语（敬请期待）」，显示今天各科是否已完成、本周星星数。
2. **章节页**：该科教材目录（按章节），每章显示题目数与已得星星；支持多选章节。
3. **答题页**：题干 + 选项 + 进度条 + 剩余时间 + 生命/连击。
4. **成绩页**：本次得分、正确率、星星、用时、错题回顾（可一键重练错题）。
5. **家长设置页**：时长、次数上限、声音、清空数据（入口在首页右下角，**点击即可进入**；清空数据等危险操作有二次确认）。

### 3.2 答题流程

选科 → 选章节（可多选）→ 从所选章节随机抽 12 题 → 逐题作答（每题答完**立即**反馈对错 + 讲解）→ 结束出成绩 → 错题可重练。

### 3.3 游戏化设计（核心卖点）

四种模式（**第一版实现前两种**，后两种预留接口即可）：

1. **闯关模式（默认）**：答对前进一格，答错扣 1 条命（共 3 条），通关得星星。
2. **配对模式**：左右两列卡片配对（汉字-拼音、图-词、算式-得数），配错抖动提示。
3. **计时挑战**：60 秒限时，答对加分，连对有连击加成。
4. **竞速答题**（可选后期）。

激励要素：

- **星星体系**：每次会话按正确率给 0~3 星；累计星星可解锁小徽章。
- **连续打卡**：每天完成所选科目，日历盖一个章；连续 7 天有庆祝动画。
- **答错不羞辱**：显示「再试一次」+ 正确提示，不做满屏红叉。
- **完成动画**：撒花 + 语音「太棒了！」。

### 3.4 10 分钟定时（硬性功能）

- 进入答题会话即开始倒计时（默认 10:00，家长可调 5/10/15 分钟）。
- 倒计时结束：当前题算未答，立即弹结算页，语音提示「今天的学习完成啦」。
- 每日每科次数限制：**默认不限制**（家长可在设置里选 1~3 次上限；设了上限后，超次数该科入口才显示「明天见」）。

> ⚠️ **实现约束（必读）**：剩余时间必须用**时间戳差值**计算——
> `剩余 = 时长 - (Date.now() - startAt)`，每次渲染时重算。
> **禁止**用 `setInterval` 每秒 `timeLeft--` 累加：iOS 切后台会冻结定时器，
> 孩子切出去再回来等于白送时间。切回前台（`visibilitychange`）时重算，若已超时立即结算。

### 3.5 成绩与错题

- 成绩页：得分（基础分 100，答错一题 −10，最低 0）、正确率、星星、用时、错题列表（题干 + 正确答案）。
- 历史记录：按日期存 localStorage，最近 7 天用柱状图展示每日正确率。
- 错题本：自动汇总所有答错过的题，可单独练习；答对 2 次后移出错题本。

### 3.6 家长设置页

- 每日时长（5/10/15 分钟）、每日次数上限（**不限制** / 1 / 2 / 3 次）、各科开关、声音开关、清空数据。

### 3.7 适龄要求（验收必查）

- 所有按钮 **≥ 88×88px**（手指友好）。
- 题干字号 **≥ 24px**，正文 ≥ 20px，拼音 rt ≥ 11px。
- 语文题**逐字带拼音**（见 5.5）；题干尽量 TTS 朗读，孩子不识字也能玩。
- 全流程**最多 2 次点击**到达答题。
- 横竖屏都可用，推荐横屏。
- 禁止双击缩放（`viewport` 设 `user-scalable=no`）、禁用长按选中弹菜单。

## 5. 题库 JSON 格式规范（v1.1）

### 5.1 文件组织

```
data/
  yuwen-1-up.json     # 语文一年级上册
  shuxue-1-up.json    # 数学一年级上册
  yingyu-1-up.json    # 英语一年级上册（占位）
```

### 5.2 顶层结构

```json
{
  "schemaVersion": "1.1",
  "subject": "yuwen",
  "subjectName": "语文",
  "grade": 1,
  "term": "up",
  "updated": "2026-09-12",
  "textbook": "人教版统编版（2024年修订）一年级上册",
  "chapters": []
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| schemaVersion | string | 是 | 规范版本，本版为 `1.1` |
| subject | string | 是 | `yuwen` / `shuxue` / `yingyu` |
| subjectName | string | 是 | 显示名：语文 / 数学 / 英语 |
| grade | number | 是 | 年级，1 |
| term | string | 是 | `up` 上册 / `down` 下册 |
| updated | string | 是 | 日期 `YYYY-MM-DD` |
| textbook | string | 是 | 教材版本说明（v1.1 起为正式字段） |
| chapters | array | 是 | 章节列表 |

### 5.3 章节结构

```json
{ "id": "yw-c2", "title": "第二单元·汉语拼音（a o e / i u ü / b p m f / d t n l）", "order": 2, "questions": [] }
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 章节唯一 ID，`yw-cN` / `sx-cN` |
| title | string | 是 | 章节名（含所含课文，便于家长辨认） |
| order | number | 是 | 排序，从 0 开始 |
| questions | array | 是 | 题目列表 |

### 5.4 题目公共字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 全局唯一，如 `yw-c2-001` |
| type | string | 是 | `choice` / `judge` / `match` / `arith` / `listen` |
| stem | string | 是* | 题干（`match` / `arith` 可省） |
| stemPinyin | string | 语文必填 | 题干注音，规则见 5.5 |
| options | array | choice/listen 必填 | 选项文本数组 |
| optionsPinyin | array | 语文 choice 必填 | 与 `options` 等长的注音数组 |
| answer | number/boolean | choice/judge/listen 必填 | choice/listen 为选项**索引**（从 0 起）；judge 为 `true/false` |
| pairs | array | match 必填 | `[{left, right, leftPinyin?, rightPinyin?}]` |
| template / range | — | arith 必填 | 见 5.7 |
| imageUrl | string | 否 | **相对路径**，指向 `assets/`（禁外链） |
| difficulty | number | 是 | 1~3（v1.1 起必填，便于分层出题） |
| modes | string[] | 是 | 可用模式：`["level","match","timer"]` 的子集（v1.1 起必填） |
| explain | string | 是 | 答题后讲解（一句话，口语化、鼓励式） |

\* 语文题**所有出现汉字的地方都要注音**（题干、选项、配对项）。

### 5.5 拼音字段规范（v1.1 新增，重点）

**规则**：拼音字段与对应文本中的**汉字按顺序一一对应**，音节之间用**单个空格**分隔；标点、数字、字母不占位。

```json
{
  "id": "yw-c5-002",
  "type": "choice",
  "stem": "秋天到了，大雁往（　）飞。",
  "stemPinyin": "qiū tiān dào le dà yàn wǎng fēi",
  "options": ["南", "北", "东", "西"],
  "optionsPinyin": ["nán", "běi", "dōng", "xī"],
  "answer": 0,
  "difficulty": 1,
  "modes": ["level", "timer"],
  "explain": "“一群大雁往南飞”，秋天大雁飞到南方过冬。"
}
```

- 选项含多个汉字时，音节同样用空格分隔：`"optionsPinyin": ["xiǎo xiǎo de chuán"]`。
- 配对题：`{ "left": "爸", "right": "bà", "leftPinyin": "bà", "rightPinyin": "bà" }`
  （`right` 本身是拼音时 `rightPinyin` 可省略）。
- **校验规则（脚本强制）**：`stemPinyin` 的音节数 **必须等于** `stem` 中的汉字个数；`optionsPinyin[i]` 的音节数必须等于 `options[i]` 中的汉字个数。不等即报错。
- **标注口径（按教材习惯）**：
  - 变调：`一` / `不` 按实际读音标注（一片 → `yí piàn`，不对 → `bú duì`）；
  - 轻声：`子` / `了` / `着` / `们` 等按轻声标注（影子 → `yǐng zi`）；
  - 儿化：按教材写法（雨点儿 → `yǔ diǎn r`）；
  - 拼音带声调符号（`ā á ǎ à`），不用数字调号；`ü` 写作 `ü`，不写成 `v`。
- 生成方式：`pypinyin` 自动标注 + **变调/轻声/儿化人工校对表**（`脚本` 见 `docs/题库修订报告.md`）。
- TTS 朗读用 `stem`（汉字），不用 `stemPinyin`（避免念成字母）；显示用拼音注音。

### 5.6 题型定义与示例

**① choice 单选** —— 见 5.5 示例。数学题可不带 `stemPinyin` / `optionsPinyin`。

**② judge 判断**

```json
{
  "id": "yw-c2-002", "type": "judge",
  "stem": "“b”是韵母。", "stemPinyin": "shì yùn mǔ",
  "answer": false,
  "difficulty": 1, "modes": ["level", "timer"],
  "explain": "b 是声母，不是韵母。"
}
```

**③ match 配对**（左右两列打乱，点左一项 + 右一项完成配对；每组至少 3 对）

```json
{
  "id": "yw-c2-003", "type": "match",
  "pairs": [
    { "left": "爸", "right": "bà", "leftPinyin": "bà" },
    { "left": "妈", "right": "mā", "leftPinyin": "mā" },
    { "left": "马", "right": "mǎ", "leftPinyin": "mǎ" }
  ],
  "difficulty": 1, "modes": ["match"],
  "explain": "看清声调再配对哦。"
}
```

**④ arith 口算**（按模板实时生成，一次会话内不重复）—— 见 5.7。

**⑤ listen 听音**（英语/拼音，TTS 朗读 `stem`；纯英文题干用 `en-US` 语音）

```json
{
  "id": "yy-c1-001", "type": "listen",
  "stem": "apple", "tts": true,
  "options": [{ "text": "苹果" }, { "text": "香蕉" }, { "text": "梨" }],
  "answer": 0, "difficulty": 1, "modes": ["level", "timer"],
  "explain": "apple 是苹果。"
}
```

### 5.7 arith 口算生成规则（**4 条硬约束必须实现**）

```json
{
  "id": "sx-c5-001", "type": "arith",
  "template": "{a} {op} {b} = ?",
  "range": { "a": [2, 10], "b": [1, 9], "ops": ["-"], "minResult": 0, "maxResult": 10 },
  "difficulty": 2, "modes": ["level", "timer"],
  "explain": "从 a 里去掉 b，数一数还剩几。"
}
```

1. **结果区间**：生成结果必须满足 `minResult ≤ 结果 ≤ maxResult`（缺省 `minResult=0`；一年级上册**不允许负数**）。
2. **减法保证 `a ≥ b`**：抽题时先定 `a`，再从与 `range.b` 的交集 `0..a` 中抽 `b`。**不得**按 `b` 的独立区间随机，否则会生成 `2 - 4` 这种负数题。
3. **去重**：一次会话内同一模板生成的题目按 `(a, op, b)` 去重；连续两题不得完全相同。
4. **模板占位符**：`template` 中若出现 `{op}`，则运算符从 `range.ops` 随机取；若模板**直接写死** `+` 或 `-`（如 `"{a} + {b} = ?"`），则忽略 `ops`。两种写法实现都要兼容。

另：`0` 的加减只在"认识 0"之后使用（`sx-c1` 之后）；第二单元若含 `0`，需在 `range` 中显式写清 `b` 从 0 还是 1 开始。

### 5.8 会话与计分规则

- 单次会话 12 题，从所选章节随机抽取；`arith` 题实时生成。
- 每题作答后立即反馈（对/错 + 讲解）再进入下一题。
- 得分：基础分 100，答错一题 −10，最低 0。
- 星级：正确率 ≥ 90% → 3 星；≥ 70% → 2 星；≥ 50% → 1 星；< 50% → 0 星（显示鼓励语）。
- 计时模式：连对 3 题 +5 分。

## 6. App 实现要点

- **拼音渲染**：用 `<ruby>` 注音 `<ruby>秋<rt>qiū</rt></ruby>`；`rt` 字号 `0.45em`、颜色 `#666`；不含拼音的字符直接输出。
- **图片**：只用 `assets/` 下的**自制 SVG**（禁止外链、禁止教材扫描图，规避版权）。
- **存档 key 设计**：`ypApp.v1.settings` / `ypApp.v1.records` / `ypApp.v1.wrong` / `ypApp.v1.checkin`，统一版本前缀便于日后迁移。
- **音效**：Web Audio 合成（正确=上行三音、错误=柔和短音），首次交互时解锁 AudioContext。
- **兼容**：目标 iOS Safari ≥ 15；使用 `-webkit-` 前缀；`viewport` 加 `viewport-fit=cover` 适配刘海屏。
- **性能**：页面切换用 CSS transform 动画，避免重排；题库加载一次后缓存在内存。
- **无障碍**：按钮含 `aria-label`；颜色不是唯一提示手段（对错有图标 + 文字）。
