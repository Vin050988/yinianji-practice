## 三、另外两个我自己查出来的隐患（已修）

**7. 「正确答案总排在第一个」**
新增题目如果原样入库，会出现答案位置严重偏斜（孩子很快学会"只点第一个"）。
→ 生成器加入**选项打乱**（按题号取固定种子，结果可复现），并同步修正 `answer` 与 `optionsPinyin`。
→ 现状：语文答案分布 **{0:21, 1:23, 2:35, 3:35}**；数学 **{0:25, 1:48, 2:33, 3:25}**。

**8. 判断题「对」占 83%**
原题库语文 20 道判断题里 17 道答案是「对」，数学 13/19 是「对」。
→ 把 **11 道**判断题改写成**等价的反面陈述**（知识点不变，答案变「错」），例如：
「zh、ch、sh、r 都是平舌音」（错）、「1 + 4 = 6」（错）、「正方体只有 3 个面」（错）。
→ 现状：语文 **10 对 / 10 错**；数学 **9 对 / 10 错**。

## 四、拼音标注（规范 5.5 首次落地）

- **自动标注**：`pypinyin`（数字调 + 轻声标记）+ 自写「数字调 → 声调符号」转换（`pian4 → piàn`、`lü4 → lǜ`）。
- **变调**（按教材实际读音）：「一」「不」自动变调 —— 一片 → `yí piàn`、不对 → `bú duì`。
- **轻声**：影子 → `yǐng zi`、瓶子 → `píng zi`。
- **儿化**：雨点儿 → `yǔ diǎn r`。

**抽检 55 处多音字，修正 3 类错误**：

| 类型 | 例 | 说明 |
|---|---|---|
| 「尾巴**长**」误标 `zhǎng` → 改 `cháng` | yw-c8-001、yw-c8-011 | `zhǎng` 是"长大"；长短读 `cháng` |
| 「**数数**」误标 `shù` → 改 `shǔ` | yw-c0-003 | 动词"数一数"读 `shǔ` |
| 「**谁**」标注 `shéi` → 改 `shuí` | 6 道题 | 按教材口径统一为 `shuí` |

其余 52 处抽检**全部正确**（含 `睡着 → zháo`、`数不清 → shǔ`、`小石子 → zǐ` 而 `沙子 → zi` 这类细节）。

**强校验**：每个拼音字段的音节数必须等于对应文本的汉字数 —— 语文 147 题**全部通过**。
