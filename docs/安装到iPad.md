# 安装到 iPad（像 App 一样用）

> 部署完成后，只要在 iPad 的 Safari 里打开一次网址，就能把它「装」到主屏幕上，
> 以后点图标直接全屏使用（没有地址栏，跟原生 App 差不多）。

## 一、准备

- iPad 连着 Wi-Fi（能上网即可）；
- 站点地址：**https://<你的用户名>.github.io/yinianji-practice/**（部署完成后填这里）

## 二、添加到主屏幕（只需做一次）

1. 在 iPad 上打开 **Safari**（一定是 Safari，微信/QQ 内置浏览器不行）；
2. 在地址栏输入上面的网址，打开后等页面完整显示（出现「一年级练习」的科目卡片）；
3. 点 Safari 顶部（或底部）的 **分享按钮** —— 一个方块带向上箭头的图标；
4. 在弹出菜单里向下找，点 **「添加到主屏幕」**；
5. 名字会自动填成「一年级练习」，点右上角 **「添加」**；
6. 回到主屏幕，就能看到新图标了。点它打开 —— 会**全屏显示，没有浏览器地址栏**。

## 三、日常使用

- 孩子直接点主屏幕上的图标即可，不需要再打开 Safari；
- 做题记录、星星、错题本都存在这台 iPad 上（localStorage），**不会上传到任何服务器**；
- 断网也能打开（有离线缓存），但第一次打开需要联网。

## 四、家长设置在哪

首页**右下角**的「家长设置」按钮，**点一下就能进**：

| 设置项 | 说明 |
|---|---|
| 每天每科时长 | 5 / 10 / 15 分钟（默认 10 分钟，到点自动结算） |
| 每天每科次数上限 | **默认「不限制」**；想限制可选 1~3 次，超了会显示「明天见」 |
| 朗读题目（语音） | 关掉就不出声（不影响答题，题目本身有拼音） |
| 音效 | 对错提示音开关 |
| 语文 / 数学 | 单独关掉某一科 |
| 最近 7 天正确率 | 柱状图，每根柱子是一天的正确率 |
| 清空所有数据 | 有二次确认，会清掉成绩、错题和星星 |

## 五、更新题目后怎么让 iPad 拿到新版

题目或代码更新并推送到 GitHub 后，iPad 上这样做：

1. 打开 Safari，访问上面的网址；
2. **下拉刷新**一次（或关掉标签页重新打开）；
3. 再点主屏幕图标进入，即是最新版本。

如果发现还是旧内容，把主屏幕上的图标**删掉重新添加**一次即可。

## 六、常见问题

**Q：点「添加到主屏幕」后打开是全屏，但看不到返回按钮怎么办？**
A：全屏模式下没有浏览器工具栏，属正常。想回到 Safari 就按 Home 键 / 上滑回到主屏即可。

**Q：孩子点错了很多次，能把数据清掉重来吗？**
A：可以。进「家长设置」→「清空所有数据」，会清空成绩、错题本和星星。

**Q：语音不响？**
A：iOS 的语音第一次使用需要用户先点一下屏幕（系统限制）；若仍无声，检查 iPad 是否静音、以及设置里是否装了中文语音包。语音关闭也不影响答题。

**Q：这台 iPad 上做过的题，换台设备能看到成绩吗？**
A：看不到。成绩只存在本机，换设备就是全新的（这也是出于隐私考虑的有意设计）。
