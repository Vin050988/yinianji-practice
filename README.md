# 一年级练习

给家里一年级孩子用的**语文 / 数学课后练习**网页应用，主要在 iPad 上打开（添加到主屏幕后像 App 一样全屏使用）。

## 它有什么

- **三科内容**：语文 147 题（人教版 2024 统编，9 个单元）、数学 162 题（北师大版 2024，10 个单元/复习）、英语 96 题（沪教版《英语口语交际》2025 新教材，6 个 Unit + Project 1/2 + 日常用语），**共 405 题**
- **语文题逐字带拼音**：所有汉字都有注音，孩子识字不多也能自己读题
- **英语听力用系统 TTS 现场朗读**（不依赖音频文件、零版权风险、离线也能出声）
- **游戏化答题**：闯关（3 条命）、连击鼓励、星星、撒花动画；配对题（左右两列卡片连线）
- **每轮 12 题**，从所选章节随机抽；答完立即反馈 + 讲解
- **成绩与错题本**：得分/正确率/用时/错题回顾，错题可一键重练（答对 2 次自动移出）
- **语音朗读题目**（可关）+ 对错音效（Web Audio 合成，无需素材文件）
- **家长设置**：每次时长（5/10/15 分钟）、每日次数上限（默认不限制）、各科开关、最近 7 天正确率图表、清空数据
- **PWA**：可添加到 iPad 主屏幕、断网也能兜底使用

## 怎么用

### 电脑上本地预览

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

Mac 上也可以直接**双击 `启动预览.command`**（会自动开浏览器并打印 iPad 可用的局域网地址）。

### iPad 上使用

见 [`docs/安装到iPad.md`](docs/安装到iPad.md)。

## 目录结构

```
├── index.html            单页应用入口（5 个页面：选科/章节/答题/成绩/家长设置）
├── css/app.css           样式（按钮 ≥88px、题干 ≥24px 的适龄要求都在这）
├── js/
│   ├── pinyin.js         拼音注音渲染（汉字上方小字）
│   ├── storage.js        本地存档（设置/成绩/错题本/打卡）
│   ├── audio.js          音效合成 + 语音朗读（含无声降级）
│   ├── engine.js         题库加载、抽题、口算实时生成
│   ├── modes.js          会话状态机（倒计时用时间戳差值，切后台不白送时间）
│   └── app.js            主控制器（页面流转、答题交互、家长设置）
├── data/                 题库 JSON（yuwen / shuxue / yingyu）
├── assets/               PWA 图标 + 30 个自制 SVG 配图（钟面/立体图形/数数/规律）
├── tools/                题库生成器与校验器（见下）
├── docs/                 规范、修订报告、自测记录、安装说明
├── manifest.json         PWA 清单
└── sw.js                 Service Worker（离线兜底）
```

## 题库怎么维护

题库采用「**原始题 + 人工补丁 + 生成器**」的方式，改题只需动补丁文件，不用手写全部 JSON：

```bash
python3 tools/build_questions.py      # 由原始题库 + 补丁生成 data/*.json
python3 tools/check_questions.py      # 校验（字段、id、答案、拼音音节数、图片）
python3 tools/make_svg.py             # 重新生成配图 SVG
```

- `tools/patch_yuwen.json`、`tools/patch_shuxue_a..d.json`：修正与新增题目
- 生成器会自动：补拼音（含「一/不」变调）、补 `difficulty`/`modes`、**打乱选项顺序**（避免孩子记答案位置）、**平衡判断题对错比例**
- 规则见 [`docs/需求说明与题库规范_v1.1.md`](docs/需求说明与题库规范_v1.1.md)
- 改题记录见 [`docs/题库修订报告.md`](docs/题库修订报告.md)
